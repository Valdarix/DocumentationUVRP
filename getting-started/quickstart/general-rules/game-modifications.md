# Game Modifications

We're committed to maintaining a fair and balanced playing field for everyone. To ensure this, please follow these guidelines:

**What's NOT Allowed:**

* Any modifications that provide gameplay advantages (enhanced vehicle handling, performance boosts, shaders proving bullet tracing, etc.)
* Cheats, hacks, exploits, or third-party scripts
* Plugins or tools that give you an unfair edge over other players

{% hint style="danger" %}
Using prohibited modifications will result in an immediate ban without appeal. This is an RP server, not a competitive server, not an arena server, you are here because you said you want to roleplay. Using cheats and mods only cheapens your experience.&#x20;
{% endhint %}

_When in doubt, ask a staff member before installing anything. We're happy to help!_
