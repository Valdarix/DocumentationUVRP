# Federal Protection Limits

EMS is a federally protected role in PHRP. However, this does come with some limits, if there are 5+ EMS on duty then ONE(1) EMS employee is allowed to be kidnapped or used as a hostage. EMS should never be taken from a scene where they are reviving or healing someone. \
\
You can NEVER steal an EMS vehicle.\
\
Using EMS as hostage or kidnapping them should be reserved for big scenes or events. They should not be a primary easy target.
