# Common Tickets

The following grid contains common issues you might encounter and how they should be handled by staff. Failure to handle the issue in the appreciate manner for all players is a failure of staff duties.

{% hint style="info" %}
If multiple situations exist in a single incident, you should deal the acceptable action for the most serious of them and educate on the other issues.&#x20;
{% endhint %}

The infractions listed under the situation are all considered the same situation and should be treated as such. For example, a first offence of **RDM** should escalate to second offense if any of the items under that situation occur.&#x20;

{% hint style="warning" %}
All tickets where a punishment or coaching is issued should include a link to the direct rule(s) that are being addressed within the ticket. Failure to cite the rule will result in removal of the infraction from the players record.&#x20;
{% endhint %}

| Situation                             | Offense # | Appropriate Action                                                                                                                                                                                              |
| ------------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RDM, VDM, Power Gaming, Meta Gaming` | First     | Re-educate the player on the rule(s) they broke providing a specific link to the Player Guide that defines the rule.                                                                                            |
| -                                     | Second    | Second incident of the player committing the same rule break will result in a warning and probationary period. If they player commits any offenses in the probationary period, they will receive a 24-hour ban. |
| -                                     | Third     | 3-day ban.                                                                                                                                                                                                      |
| -                                     | Fourth    | 7-day ban.                                                                                                                                                                                                      |
| -                                     | Fifth     | A person who has gotten 5 infractions for RDM, VDM, Power Gaming or Meta Gaming obviously has no respect for the rules and will receive complete removal from the server. They can reapply in 30 days.          |
