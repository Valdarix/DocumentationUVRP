# Important Keybinds and Commands

Below you will find a list of general keybinds for playing in the city. These keybinds and commands apply to all players. Note that these are the default settings, you may have changed them in your FiveM keybinds.&#x20;

While these key binds are the default key binds and slash commands for the server, you should customize them to suit your needs in the Settings menu. Many scripts often use the same default key bindings so customizing them will make your experience enjoyable.&#x20;

Slash commands are entered by pressing `T` and entering the command in your chat box.&#x20;

Also, some interactions are available in your radial menu `F1` or `Z` by default, this menu allows you to perform certain actions but is currently a work in progress.&#x20;

| Keybind       | Command      | Action                                                                                                                  |
| ------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------- |
| `TAB`         |              | Open Inventory                                                                                                          |
| `P` or `ESC`  |              | Open your map/pause menu                                                                                                |
| `I`           |              | Open UI/Hud customizations                                                                                              |
| `X`           |              | Cancels most actions in the game                                                                                        |
| `H`           |              | Handsup Emote, you will get used to having your hands up.                                                               |
| `E`           |              | Interacts with most things that use interact instead of third eye, such as unlocking doors or opening the garage menu.  |
| `LALT`        |              | Enables your third eye, this is used to interact with objects using a mouse click.                                      |
| `F1`          |              | Opens your phone                                                                                                        |
| `Z`           |              | <p>Multiple: Should change some of them.<br>1. Radial Menu<br>2. Minimap scaling<br>3. Inventory Hotbar</p>             |
| `N`           |              | Default for push to talk, if you have a lot of backgorund noise it is suggested that you use PTT                        |
| `~`           |              | Adjusts your speaking volume.                                                                                           |
| `HOME`        |              | Open the scoreboard                                                                                                     |
|               | `/skills`    | See your current skills                                                                                                 |
| `G`           |              | Start and stop your vehicle engine                                                                                      |
| `LCTRL`       |              | Crouch                                                                                                                  |
| `RCTRL`       |              | Crawl                                                                                                                   |
| `K`           |              | Open vehicle extras menu                                                                                                |
|               | `/milkdudd`  | Call the AI doctor, there are restrictions to this, and he will respawn you at the hospital.                            |
| `B`           |              | <p>Multiple:<br>1. Point<br>2. Put on and remove seatbelt</p>                                                           |
| `F10`         |              | Open the multi-job menu                                                                                                 |
| `F4`          | `/emotemenu` | Open the emote menu                                                                                                     |

You will find key binds specific to Jobs, Crime, and other actives in the respective sections for those features.
