# Megaphone

{% embed url="https://youtu.be/XXhKl5hbJLE" %}

{% hint style="danger" %}
Megaphones can be stolen and used by players.&#x20;
{% endhint %}

The megaphone is equipped and used like weapons and can be purchased in the armory at any police station.&#x20;

![](../../.gitbook/assets/FiveM_b3407_GTAProcess_1tQRmCYutI.png)

### Key binds

| Key                 | Function                            |
| ------------------- | ----------------------------------- |
| `K`                 | Activate Megaphone in a car.        |
| `LEFT MOUSE BUTTON` | Use megaphone while it is equipped. |
