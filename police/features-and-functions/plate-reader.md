# Plate Reader

We use the well-established WK wars plate reader in our city.&#x20;

{% hint style="info" %}
If you are having trouble with your radar you can do the following:&#x20;

1. Press T
2. Enter `/reset_radar_data` and press Enter
3. Now logout of the game and restart it. The plater reader should then work again.
{% endhint %}

## Default key binds

Although these can be viewed in game through the operator manual, the default key binds are listed below.

<table><thead><tr><th width="227">Action</th><th width="224">Key</th><th>Description</th></tr></thead><tbody><tr><td>Open remote</td><td>F5</td><td>Opens the remote control, this only works if you are the driver of a police vehicle (must have the vehicle class VC_EMERGENCY).</td></tr><tr><td>Close remote</td><td>ESC or right mouse button</td><td>Closes the remote/all of the displayed UI elements, and returns focus to the game.</td></tr><tr><td>Lock/unlock front antenna</td><td>Numpad 8</td><td>Locks the current speed of the front antenna. If there is a fast speed displayed, the system will lock the fast speed. Otherwise it will lock the strong speed. When you lock a speed, the radar will audibly tell you which antenna is being locked, and the relative direction of the target compared to the patrol vehicle (e.g. "Front Closing").</td></tr><tr><td>Lock/unlock rear antenna</td><td>Numpad 5</td><td>Locks the current speed of the rear antenna. If there is a fast speed displayed, the system will lock the fast speed. Otherwise it will lock the strong speed. When you lock a speed, the radar will audibly tell you which antenna is being locked, and the relative direction of the target compared to the patrol vehicle (e.g. "Rear Away").</td></tr><tr><td>Lock/unlock front plate</td><td>Numpad 9</td><td>Locks the plate currently caught by the front plate reader, an audible beep will also be heard unless the plate reader audio option in the operator menu is changed.</td></tr><tr><td>Lock/unlock rear plate</td><td>Numpad 6</td><td>Locks the plate currently caught by the rear plate reader, an audible beep will also be heard unless the plate reader audio option in the operator menu is changed.</td></tr><tr><td>Toggle keylock</td><td>L</td><td>Toggles the keylock state. When enabled, none of the keybinds will work until keylock is toggled again.</td></tr></tbody></table>
